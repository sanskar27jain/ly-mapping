# LY Mapping

Tools for reconstructing and analyzing three-dimensional light-yield maps using crossing-muon data.

## Repository contents

This repository contains source code for constructing the linear system, solving for voxelized light yield, applying smoothness regularization, and analyzing reconstruction performance.
